# 📝 Blog App

A simple **Flutter Blog App** built with **Clean Architecture**, **BLoC**, **Supabase**, **Hive**, and **GetIt**.  
Users can sign up, log in, create blogs, and read them easily with a clean UI.

---

## ⚙️ Tech Stack
Flutter • BLoC • Supabase • Hive • GetIt
